# Corpus de démonstration

Ces fiches sont des **données de démonstration** rédigées pour tester le pipeline.
Elles ne remplacent pas les sources officielles : avant toute utilisation réelle,
remplacez-les ou complétez-les par des documents officiels (portails des ministères,
municipalités, JORT, guides de l'APII / RNE, etc.) au format `.md`, `.txt` ou `.pdf`,
puis relancez `python -m sanad.ingest`.

Les montants et délais exacts sont volontairement marqués « à vérifier ».
